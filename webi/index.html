about

I'm a network engineer and technician from Halabja, now based in Sulaimani, building a career at the intersection of infrastructure and automation.

My work has taken me from pulling cable and configuring customer-premise equipment as a Network Technician, to designing and troubleshooting networks as a Network Engineer for a home internet service provider in Halabja. Along the way I picked up Linux administration, Python and Java for tooling, and the fundamentals of .NET — because a network engineer who can also script and automate is a more useful one.

I'm currently a student in the Network department at Sulaimani Polytechnic University, and I'm working toward the CCNA and CCNP certifications to formalize and extend what I've already learned in the field. My longer-term interest is network automation and NetDevOps — using code to make networks easier to build, verify, and repair.
